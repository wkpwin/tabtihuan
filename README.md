# 书签URL批量替换工具

一个Chrome扩展程序，用于批量替换浏览器书签中的URL地址。

## 功能特性
- 批量查找和替换书签URL
- 支持正则表达式匹配
- 替换前预览更改
- 自动备份原始书签

## 安装方法
1. 下载或克隆本仓库
2. 打开Chrome浏览器，进入`chrome://extensions/`
3. 启用"开发者模式"
4. 点击"加载已解压的扩展程序"，选择本项目的根目录

## 使用方法
1. 点击浏览器工具栏中的扩展图标
2. 在弹出窗口中输入查找和替换的URL模式
3. 点击"预览"查看匹配结果
4. 确认无误后点击"执行替换"

## 开发
```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```
